# Buildings V1.6 — WarLike Studio

32 original vector building prefabs across RTS, City, Fantasy, Survival, Military and Sports. This pack is part of the offline Project Browser category **Buildings**; existing assets are unchanged. Asset total: 147.

**Editor:** Select Buildings in Project / Assets. Click once to preview, double-click to instantiate, or drag onto the Scene. Select a building to configure its **Building Controller** in Inspector: grid size and snap, team, powered state, construction progress, HP, max HP, collision, upgrade level, unit production type, queue length and production interval.

**Play mode:** Built buildings block pedestrians and vehicles when solid. Shooting damages them and can destroy them. Under-construction, damaged, destroyed, unpowered and burning appearances are illustrated on the Canvas. Queue production in Barracks or Factory to spawn basic units when powered; production is intentionally lightweight (no resource economy, tech tree, pathfinding or rally points).

**Test scene:** Game → Building / RTS Demo, then Play. Barracks queue three soldiers, Factory queues two jeeps. Construction of the Fantasy Castle progresses automatically. A scout is present for movement and combat.

**Limitations:** 2D stylized original SVGs, not imported 3D models, structural building interiors, or full RTS construction/economy simulation. Production doesn't enforce costs or power network connectivity. Complex navigation mesh / unit obstacle avoidance is not included. Code syntax checked, but browser deployment and complete interactive testing still need verification.
