# WarLike Engine Web

Prototype autonome d'éditeur 2D. Ouvrir `index.html` ou héberger le dépôt sur Cloudflare Pages.

## Fonctionnalités
- Hiérarchie et Inspector, création et déplacement d'objets.
- Mode Play / Stop avec déplacement clavier et collisions AABB simples.
- Import / export de scènes JSON.

## Déploiement Cloudflare Pages
Connecter le dépôt GitHub `Motherlode94/WarLike-Engine` à Cloudflare Pages. Framework : None, build command : vide, output directory : `/`. Aucun domaine ni hébergement n'est créé automatiquement par ce dépôt.

## Provenance des sources
Cette V0.1 est un prototype original, **pas encore** un fork de Phaser et ne contient pas de sources de moteurs tiers. La prochaine phase intégrera des fichiers sources en conservant les licences, avis et historique de provenance.
