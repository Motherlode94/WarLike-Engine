Importer un prefab depuis Library

Sélectionne le fichier .wlpkg.json exporté par Library. Engine vérifie l’empreinte SHA-256 et les maillages du GLB, conserve les octets du modèle dans IndexedDB, puis installe le prefab dans la bibliothèque locale du moteur.

Cette importation fonctionne sur le navigateur et le domaine d'Engine. Les fichiers sont conservés localement, pas dans un compte cloud. La configuration complète Animator, Rigidbody et scripts nécessite encore une vérification dans l’Inspecteur avant Play/Export.
