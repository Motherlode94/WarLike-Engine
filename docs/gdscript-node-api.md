# GD03 — Node compatibility
Node exposes the current object's name (read only). Node2D and Node3D map to WarLike scene objects and must match scene dimensionality. `position` uses WarLike scene metres (64 internal units per metre, unlike Godot 2D pixels). `Vector2(x,y)` uses the existing Vector3 representation with z=0; inspector exposes the underlying three components. `rotation` is radians; `rotation_degrees` degrees; Node3D supports individual x/y/z axes. `rotate(angle)` for Node2D, `rotate_x/y/z` for Node3D. `translate`/`global_translate` are scene-coordinate displacements, not Godot local-axis transforms. `visible`, `show`, `hide` map to native rendering visibility. No hierarchy lookup, parenting, local/global transform conversion, SceneTree, instantiation or queue_free yet. This profile is not a drop-in Godot runtime. Native scene mutation and dimension guards tested; browser/export acceptance pending.
