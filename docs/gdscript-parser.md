# GODOT02 — Structured GDScript frontend
The existing v0.3 supported profile now passes through a dedicated lexer, indentation tokens, statement/expression AST and explicit lowering into the bounded WarScript interpreter. No eval, no generated JS; string content is not rewritten. Lexer/parser errors carry source line and column, backend diagnostics map to original statement tokens. Existing GD01–GD03b tests remain unchanged. The supported language is still a subset, not the full Godot grammar: no arrays, dictionaries, await, arbitrary node references, inheritance, multiline expressions or full static typing. Coordinates and node lifecycle are unchanged in this PR. Browser/export validation remains necessary.
