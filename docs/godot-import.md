# Godot 4 interoperability — GD03b
Import a project directory from File → Importer Godot (.tscn / .gd); select a text scene, then append the validated native entities to the current workspace. The original files are never modified or executed by the importer. Supported subset: Node, Node2D, Node3D, Camera2D, Camera3D, DirectionalLight3D, OmniLight3D, SpotLight3D, MeshInstance3D with simple embedded BoxMesh/SphereMesh. Parent paths, transforms and linked .gd sources are converted; unsupported node types, connections, scene instances, properties, missing scripts and incompatible dimensions reject the import. Godot 4 format=3 only. 2D scene positions are pixels; current GDScript runtime positions use WarLike metres, so imported scripts may need adaptation. No automatic asset loading, complete SceneTree, full physics, Godot resource format or project.godot support. Camera/light rendering equivalence is not certified. Reference: https://docs.godotengine.org/en/4.5/engine_details/file_formats/tscn.html .
