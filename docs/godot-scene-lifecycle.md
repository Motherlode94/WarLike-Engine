# A03 / GODOT03 — SceneTree callback ordering
Use native parentId hierarchy; no duplicate scene storage. GDScript enter/physics/process phases follow stable tree preorder; ready follows postorder; removal and stop use previous reverse preorder. The relative order of existing WarScript components is unchanged, including in mixed scenes. Native entity order defines siblings. Cycles and duplicate IDs reject GDScript execution; missing parent IDs act as native scene roots. Existing activation flags, saved instance state and fixed-step scheduling remain authoritative; no changes to the shared ScriptLifecycle contract. This is not complete Godot SceneTree: add/remove_child, queue_free, request_ready, process modes/priorities, reparent exit/reentry, groups and NodePath remain future work. Reference: https://docs.godotengine.org/en/stable/classes/class_node.html . Unit tests cover ordering, removal, mixed runtime and invalid trees; browser/export acceptance pending.

Late-phase detachment uses the same reverse-tree disposal pass as sync, before lifecycle refresh; a gameplay removal between update and late cannot invert exit order. Regression coverage includes in-place subtree removal and script removal, without duplicate exit callbacks.
