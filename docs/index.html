1. Démarrer avec WarLike Hub

À l’ouverture, le WarLike Hub permet de créer un projet nommé en choisissant 2D ou 3D. Les deux modes ont des bibliothèques et des simulations différentes. Pour ouvrir un projet existant, clique sur Ouvrir dans la liste des projets récents.

  1. Saisis un nom descriptif, par exemple Fracture Line.
  2. Choisis Projet 2D pour les sprites, RPG, RTS et jeux d’action 2D, ou Projet 3D pour les volumes et modèles GLB.
  3. Clique sur Créer le projet.
  4. Retrouve le Hub avec le bouton ▦ Hub en haut de l’éditeur.

Tu peux choisir une couleur pour chaque projet. Les couleurs personnalisées sont enregistrées dans ses métadonnées locales. L’option Récupérer le projet précédent peut récupérer une ancienne sauvegarde locale.

Le Hub n’est pas encore un stockage en ligne de projets : ses données sont enregistrées dans le navigateur. La suppression des données du site peut les effacer.

Hero Forge : super-héros et systèmes partagés

Dans le Hub, choisir Hero Forge · Super-héros en 2D ou 3D. Une mission jouable réunit pouvoirs, escouade, monstres, décors destructibles, secours et réseau énergétique, avec les ressources locales Kenney et Quaternius.

1–6 : trait d’énergie, onde de choc, ruée, bouclier, vol et ralliement. E : secourir / réparer. U : améliorer la branche RPG choisie. Les composants Progression RPG, Émetteur FX, Simulation et Unité tactique RTS fonctionnent aussi dans les autres genres.

Les effets sont prévisualisables dans l’Inspecteur ; le HUD affiche les coûts et recharges et se replie sur un petit écran. Voir le guide complet Hero Forge pour les contrôles, composants, actions Blueprint et limites.

Contrôles, collisions et diagnostics

Les déplacements 3D, le vol, les véhicules et les corps physiques partagent des collisions balayées. Les parois fines bloquent les mouvements rapides ; les objets désactivés sont exclus. Le personnage suit les plateformes mobiles et dispose de réglages de marche et de tolérance de saut.

La caméra se rapproche devant un obstacle et revient progressivement. Le tir FPS est bloqué par les murs ; l’altitude compte dans le combat. Les dialogues, l’inventaire et le journal bloquent les commandes de jeu. Dans Blueprint, le diagnostic sélectionne et cadre le nœud en erreur. Paramètres et limites du runtime.

3. Créer une scène 2D

Le moteur 2D inclut des objets, personnages, animations, collision AABB simple, véhicules, interactions, dialogues et démos spécialisées. Utilise les menus Assets ou Project / Assets pour ajouter des éléments.

Les démos permettent d’explorer des cas concrets : combat, conduite, RPG, logique visuelle, Ninja/Zombies et bâtiment/RTS. Certaines fonctionnalités restent expérimentales.

4. Créer une scène 3D

Le moteur 3D utilise un rendu WebGL indépendant. Il possède une caméra orbitale, des primitives géométriques, des matériaux simples, des sources lumineuses et des sources audio spatialisées expérimentales.

L’Inspector du projet 3D donne accès aux paramètres de couleur, rugosité et métal. Les démos disponibles incluent Ville, Nature et Garage.

Les prefabs procéduraux (maisons, voitures et personnages construits avec des volumes) sont stylisés. Pour afficher de vrais polygones détaillés, utilise un modèle GLB comme décrit ci-dessous.

5. Importer de vrais prefabs 3D (.glb)

Modèles intégrés de démonstration

Dans un projet 3D, ouvre Project / Assets et cherche les exemples tels que Cesium Man, Fox, Duck, Lantern, BoomBox, Toy Car ou Antique Camera. Ils proviennent des exemples Khronos glTF et sont chargés à la demande.

Bibliothèques gratuites de vrais modèles 3D

Dans Project / Assets en mode 3D, ouvre 🌐 Bibliothèques 3D gratuites. Les liens pointent vers les sites officiels. Télécharge le modèle depuis sa page, vérifie la licence de l'asset, puis importe son fichier .glb dans le moteur.

SourceSpécialitéLicence

Si le téléchargement fournit un .fbx ou un .obj, ouvre-le dans Blender, puis exporte-le au format glTF 2.0 (.glb). Les textures et animations complexes peuvent encore être partiellement prises en charge par WarLike.

Importer ton propre personnage, arme ou véhicule

  1. Prépare un fichier .glb glTF 2.0, idéalement exporté depuis Blender.
  2. Dans Project / Assets, clique sur Importer un modèle GLB.
  3. Choisis ton fichier (limite actuelle de 25 Mo).
  4. Sélectionne la catégorie Characters, Weapons, Vehicles ou Props.
  5. Ajoute le prefab à la scène par double-clic ou glisser-déposer.

La géométrie réelle du modèle est décodée en triangles puis affichée dans WebGL. Les couleurs des matériaux peuvent être simplifiées : le moteur ne prend pas encore en charge toutes les textures glTF, les animations squelettiques, les modèles compressés Draco/Meshopt ou les accessoires attachés à des os.

Important : un GLB importé depuis ton ordinateur reste en mémoire pendant la session. Le JSON de la scène mémorise sa référence, mais n’incorpore pas le fichier GLB. Après rechargement de la page, il faudra l’importer de nouveau. Les modèles en ligne nécessitent une connexion et un accès CORS autorisé par l’hébergeur.

Pour les droits d’utilisation des exemples, consulte le catalogue Khronos et les licences individuelles.

6. Visual Logic — programmation sans code

Sélectionne un objet, puis ouvre Inspector → Logic Sequences. Ajoute un composant ou choisis un exemple préconfiguré (porte verrouillée, interrupteur, événement temporisé).

ÉlémentRôle
TriggerLancer une séquence au démarrage, à l’interaction, à l’entrée/sortie d’une zone, à une touche, à un signal ou à un intervalle.
ConditionsComparer des variables globales/locales, tester une distance, combiner plusieurs conditions.
InstructionsAfficher un message, définir/modifier une variable, attendre, déplacer ou colorer un objet, envoyer un signal.
IF / ELSE IF / ELSEChoisir la première branche dont toutes les conditions sont vérifiées.

Exemple : ouvrir une porte

Trigger: Interact (E) → IF hasKey == 1 → afficher « Porte ouverte » et changer la couleur, ELSE → afficher « Porte verrouillée ».

La logique est réinitialisée lors de Play/Stop et s’exécute localement dans le mode 2D ou 3D choisi. Ce système est inspiré de l’organisation de Game Creator, mais n’en est pas une copie.

Physique 3D expérimentale — Rigidbody

Dans un projet 3D, sélectionne un objet puis ouvre Inspector → Physics 3D • Rigidbody et clique sur Add Rigidbody 3D. Tu peux régler Mass, Gravity, Bounciness, Friction, les composantes de vitesse et le mode Kinematic.

En mode Play, le composant applique une gravité, des impulsions et des collisions AABB simplifiées. Les paramètres sont inclus dans l'export/import JSON. Les personnages jouables et les agents IA restent pilotés par leurs contrôleurs dédiés.

Ce module est un prototype : il ne remplace ni PhysX, ni des contacts 3D robustes, ni un solveur de contraintes. Aucune collision précise de triangles, de pente, de joint, ni corps rigide rotatif n'est implémentée.

Le contrôleur se déplace sur le plan X/Z représenté par les coordonnées x/y des entités. La collision repose sur des rectangles simplifiés, et non sur une simulation physique rigide.

Inventaire et équipement

  1. Ajoute Inventaire à ton personnage.
  2. Saisis un ID d'objet, par exemple sword, puis clique sur ＋ Objet.
  3. Utilise Arme pour l'équiper dans le slot weapon ou Armure pour le slot armor.
  4. L'attaque 3D utilise actuellement des valeurs simplifiées : une arme équipée donne 35 dégâts et 180 unités de portée au lieu de 15 dégâts et 110 unités sans arme.

Le rendu d'une arme GLB et le slot d'équipement restent distincts : équiper un objet ne l'attache pas automatiquement à la main du personnage. Il n'existe pas encore de système de balistique 3D, de rechargement ou de projectiles complet.

8. IA, combat et séquences de comportements

Créer un ennemi

  1. Ajoute un personnage ou un prefab dans la scène 3D.
  2. Dans l'Inspector, ajoute AI State Machine et Stats.
  3. Configure Rayon détection, Portée attaque, Vitesse, Dégâts et Cooldown.
  4. Ajoute un personnage jouable, lance Play et approche-toi de l'ennemi.

Transitions actuelles : patrol quand la cible est éloignée, chase quand elle est détectée, attack à courte portée et dead lorsque sa vie atteint zéro. L'IA utilise maintenant une recherche de chemin A* sur grille pendant la poursuite, avec recalcul périodique et évitement local de secours. Dans l'Inspector, les paramètres Navigation A*, Taille cellule A* et Recalcul chemin (s) contrôlent le système. Il ne s'agit pas encore d'un NavMesh 3D : les passages étroits, la verticalité et les obstacles dynamiques demandent davantage de travail.

Logique visuelle

Ouvre Inspector → Logic Sequences et ajoute un trigger, des conditions, puis des instructions. Le panneau Graphique des comportements montre le chemin d'exécution, ses branches IF/ELSE et les instructions dans l'ordre. C'est une prévisualisation : on édite les séquences via les formulaires de l'Inspector, et non en reliant des nœuds à la souris.

FamilleExemples
ConditionsdistanceLess, distanceGreater, healthBelow, healthAbove, hasTag, variable, localVariable, randomChance
InstructionsmoveObject, teleportObject, setHealth, addHealth, setAnimation, setBehavior, giveItem, removeItem, equipItem, damageObject, healObject, wait, emitSignal

Les instructions ciblant un autre GameObject acceptent son ID. Sans ID cible valide, elles s'appliquent à l'objet qui porte la séquence.

Pour créer plus vite, sélectionne un objet dans la Hierarchy, ouvre Inspector → Quick Start • Gameplay Recipes, choisis un modèle puis clique sur Appliquer le modèle. L'éditeur demande confirmation avant de remplacer les composants concernés.

9. Tutoriel : un garde, une arme et une porte

  1. Dans WarLike Hub, crée un Projet 3D nommé « Démo Gameplay ».
  2. Sélectionne le personnage jouable. Ajoute les composants Stats, Character Controller 3D et Inventaire.
  3. Ajoute l'objet sword à son inventaire et équipe-le comme arme.
  4. Ajoute un deuxième personnage, puis AI State Machine avec une détection de 450, une portée de 65 et une vitesse de 75.
  5. Ajoute un objet représentant une porte. Dans Logic Sequences, sélectionne l'événement interact et ajoute une instruction message « Porte activée ».
  6. Dans Graphique des comportements, examine l'ordre des nœuds.
  7. Lance Play : déplace-toi avec ZQSD, esquive avec Ctrl, attaque avec F et interagis avec E.

Les composants et leur exécution restent expérimentaux. Exécute npm test et npm run typecheck dans le projet cloné puis valide les interactions dans ton navigateur.

8. Sauvegarde, projets et partage

Le bouton ↓ en haut du studio sauvegarde le projet local nommé. Export JSON permet d’enregistrer une scène sur ton ordinateur. Pour restaurer une scène, utilise Import JSON.

Attention : les fichiers GLB importés localement, les fichiers audio de session et autres ressources binaires ne sont actuellement pas emballés avec l’export JSON.

10. Personnaliser l'éditeur et ses panneaux

Dans la barre supérieure, ouvre 🎨 Éditeur : choisis une couleur d'accent, utilise l'une des huit teintes ou la palette libre, puis règle la taille de l'interface entre 75 % et 140 %. Ces préférences sont stockées dans ton navigateur et sont distinctes de celles du Hub.

Pour déplacer la séparation entre la hiérarchie, la scène et l'Inspector, fais glisser les barres verticales. Pour détacher un panneau compatible, utilise son bouton d'ancrage, ou déplace son en-tête. Le menu Affichage → Disposition des fenêtres propose Défaut, Grande scène, Inspection et Bibliothèque, ainsi que l'enregistrement et la restauration d'une disposition personnalisée.

Maximiser la scène masque les panneaux annexes ; utilise le même bouton ou Échap pour restaurer l'espace de travail. Le déplacement libre de tous les onglets entre zones, à l'identique de Unity, n'est pas encore pris en charge.

11. Importer mes assets 3D depuis le PC

  1. Ouvre un projet 3D, puis Project / Assets.
  2. Dans Mes assets 3D — importer un dossier, sélectionne toi-même un dossier avec le sélecteur du navigateur (par exemple L:\\Assets\\A).
  3. Le module recherche les .glb et répartit les fichiers dans les catégories Characters, Weapons, Vehicles, Buildings, Nature ou Imported 3D.
  4. Double-clique un modèle ou glisse-le dans la scène, puis vérifie son aspect et ses dimensions dans l'Inspector.
FormatSupport actuelPrécision
.glbImport local / dossierGLB 2.0, jusqu'à 25 Mo par fichier ; certaines géométries glTF non prises en charge.
.fbxDétection seulementÀ convertir en GLB (par exemple via Blender). Un fichier FBX n'est pas importé comme mesh natif.
.gltfDétection seulementLes glTF texte et leurs ressources externes demandent un traitement distinct.
Textures et animationPartiel / expérimentalLa présence d'un GLB ne garantit pas ses textures, son squelette ni ses animations.

Les modèles GLB locaux peuvent être enregistrés dans IndexedDB pour être restaurés après rechargement. Cela dépend du navigateur, de sa capacité de stockage et du mode privé ; garde toujours les originaux sur le PC. Le bouton Supprimer mes GLB enregistrés efface la bibliothèque locale sauvegardée.

Important : un export JSON de la scène n'embarque pas les octets de tes GLB personnels. Une scène exportée sur une autre machine peut donc nécessiter de réimporter ses assets. WarLike ne peut pas parcourir ton disque sans sélection explicite du dossier.

12. Armes, véhicules et personnages : modèle versus gameplay

Un modèle 3D représente la géométrie visible. Un prefab de gameplay demande en plus un contrôleur, des collisions, des comportements, un inventaire ou un système de combat selon son usage. Ne confonds pas « modèle visible » et « fonctionnalité jouable ».

ObjetDéjà utilisableTravail restant
ArmeAfficher un mesh GLB, lui donner une positionFixation à une main animée, rechargement, projectile, recul et effets
VéhiculePlacer un modèle et régler ses collisions de baseRoues, suspension, transmission, entrée/sortie et conduite 3D réaliste
PersonnageScène, contrôleur expérimental, saut et états de déplacementSkinning, rig, animations et transitions réelles

13. Diagnostics de projet et validation

Dans le WarLike Hub, ouvre Project Diagnostics après avoir créé ou ouvert un projet. L'analyse signale notamment les identifiants en double, positions et dimensions invalides, l'absence de joueur et certains assets 3D manquants. Tu peux télécharger le rapport JSON.

L'indicateur « prêt pour export de scène » ne signifie pas « prêt pour un exécutable autonome ». Les builds de jeux complets restent une fonctionnalité à développer et valider.

Un GLB reste un cube ou « indisponible »

Dans la vue 3D, consulte le message d'état et la console F12. Une réponse HTTP, un problème CORS, un modèle supérieur à 25 Mo ou une extension glTF non gérée peuvent bloquer l'affichage. Si le fichier est présent sur le PC, essaie son import direct et vérifie son format.

Un modèle importé disparaît

Vérifie que le navigateur autorise IndexedDB, que tu utilises le même navigateur et profil et que ses données de site n'ont pas été effacées. Le stockage local n'est pas synchronisé entre appareils.

Tester le dépôt

Pour les développeurs : npm install, npm test et npm run typecheck. Les tests unitaires ne remplacent pas les essais de rendu WebGL sur machine réelle.

9. Dépannage et limites

Le Hub ne s’affiche pas

Actualise la page avec Ctrl + Maj + R. Vérifie la version affichée dans la barre supérieure et ouvre la console du navigateur avec F12 si l’initialisation échoue encore.

Un asset 3D apparaît sous forme de cube

Le cube peut être un indicateur de chargement ou d’échec du GLB. Vérifie la connexion réseau, la taille du modèle, les restrictions CORS et la console.

Mon arme 3D est visible mais inutilisable

Afficher un modèle d’arme ne crée pas automatiquement un système de tir, de rechargement, d’animation ou d’attachement aux mains. Ces composants doivent encore être développés pour la 3D.

Le modèle est déformé ou sans textures

Les transformations, matériaux, UV et animations glTF ne sont que partiellement pris en charge. Le moteur est encore en bêta.

Les fonctionnalités annoncées ici correspondent au code du projet et à ses limites connues. Leur comportement complet n’a pas encore été vérifié dans tous les navigateurs et GPU.
