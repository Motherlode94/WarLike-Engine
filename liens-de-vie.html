C# Runtime · .NET 8

Exécute les composants C# dans le processus .NET local, puis synchronise leurs transformations dans la scène.

dotnet run --project csharp/WarLike.Bridge
Conduite C# · véhicule sélectionné

Ajoute VehicleController au GameObject dans l’Inspector, puis synchronise la scène avec .NET.

Chaque commande s'applique au prochain pas de simulation C#, pas au Play navigateur.
Genres C# · RP / Racing / Simulation / RPG / 4X

Après synchronisation, sélectionne un GameObject qui possède le composant C# correspondant, puis lance une action native.

Aucune action exécutée.

Runtime déconnecté. .NET 8 doit être lancé sur ton PC.

Éditer le script C# du GameObject sélectionné
Le code est sauvegardé dans le GameObject et dans l’export JSON de la scène. Pour l’exécuter : compiler ce script avec le SDK .NET, puis enregistrer son composant dans le runtime C#.
Pas de compilation C# dans le navigateur. Le pont local doit être démarré manuellement. L’étape C# modifie les objets éditables : sauvegarde ton projet avant de l’utiliser.
